# Senior DevOps Interview Bank

634 interview questions with model answers for a Senior DevOps Engineer (SRE / Platform Engineering) role, from basic to lead level.

**Open the page:** https://ratnamalajajee.github.io/devops-interview-bank/

## What it covers

- Linux (RHEL, Oracle Linux, Ubuntu), networking, Bash, Git
- Python, Go and platform APIs
- AWS: IAM, VPC, EC2, S3, RDS, EKS, security services, observability, DR, CloudFormation; plus Azure, GCP and OCI
- Docker, Kubernetes, Helm, GitOps, service mesh
- Terraform, Ansible, Packer, CI/CD and release practice
- SRE, monitoring, logging, incident management, DevSecOps, secrets, financial-services compliance
- Platform engineering, system design, production troubleshooting, leadership and behavioural questions

## Using the page

- Filter by level (Basic, Intermediate, Advanced, Scenario), search, or jump to a topic.
- Open answers one at a time, or show all of them.
- Tick questions you have practised. Ticks are saved in your browser only.
- **Copy shown** copies the visible questions, plus any open answers.

The whole app is the single file `index.html`. There is no build step.
